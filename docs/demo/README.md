# RetailMind local walkthrough

`retailmind-walkthrough.webm` is a silent, captioned recording of the local six-page dashboard and its real API responses. It covers the overview, customer recommendation, historical replay with outcomes revealed explicitly, product similarity, model evaluation and data quality. It was recorded at 1280×720 in Chrome with the UCI Online Retail II bundles used for the reported offline results.

The recording illustrates a local run. It does not demonstrate a Docker Compose launch, public deployment, online experiment or measured business impact. Follow `docs/demo_script.md` for a live narration and `docs/screenshots/` for desktop and mobile captures.
